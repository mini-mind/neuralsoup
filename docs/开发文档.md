# NeuralSoup 开发文档

## 项目概述

NeuralSoup 是一个基于 Web 的神经网络仿真和可视化平台，支持交互式神经网络设计、实时仿真和多关卡学习体验。项目采用 TypeScript + React + PixiJS 技术栈，提供高性能的图形渲染和流畅的用户交互。

## 项目架构

### 设计原则
- **分层架构**: 核心逻辑与UI完全分离
- **事件驱动**: 组件通过EventBus松耦合通信
- **模块化**: 每个模块职责明确，接口清晰
- **类型安全**: 完整的TypeScript类型定义

## 关卡系统

### 设计理念
- **配置化管理**: 通过配置文件统一管理关卡信息，便于扩展和维护
- **渐进式解锁**: 基于前置关卡完成情况的解锁机制
- **多维度描述**: 包含难度、预计时间、特性描述等多维度信息
- **本地化支持**: 完整的中英文界面和描述

### 关卡配置 (LevelConfig.ts)
```typescript
interface LevelConfig {
  id: string;                    // 关卡唯一标识
  level: number;                 // 关卡序号
  nameKey: string;              // 多语言名称键
  descriptionKey: string;       // 多语言描述键
  worldType: string;            // 对应的世界类型
  difficulty: 'easy' | 'medium' | 'hard';  // 难度等级
  estimatedTime: number;        // 预计完成时间(分钟)
  unlockConditions?: {          // 解锁条件
    previousLevel?: number;     // 需要完成的前置关卡
  };
  features: string[];           // 关卡特性列表
  icon: string;                 // 关卡图标
}
```

### 当前关卡
1. **第一关：追光者** (`light-seeker`)
   - 难度：简单
   - 预计时间：10分钟
   - 特性：光源追踪、基础移动
   - 插件：光感受器 + 梯度移动控制器

2. **第二关：光影花园** (`luminous-garden`)
   - 难度：中等
   - 预计时间：15分钟
   - 特性：复杂光影环境、视觉导航
   - 插件：光感受器 + 视觉感受器 + 移动控制器

### 关卡选择界面
- **LevelSelectionModal**: 关卡选择模态框
- **进度跟踪**: 显示已完成关卡和总体进度
- **解锁状态**: 可视化关卡解锁状态
- **响应式设计**: 支持移动端和桌面端

## 神经网络系统

### 神经元模型

#### INeuron 接口
```typescript
interface INeuron {
  update(input: number, deltaTime: number): void;
  reset(): void;
  getState(): NeuronState;
}
```

#### IzhikevichNeuron 类
基于Izhikevich 2003年模型的神经元实现：
- 支持不同类型：input、hidden、output
- 自动根据类型设置合适的参数
- 实现了完整的动力学方程

### 突触模型

#### ISynapse 接口
```typescript
interface ISynapse {
  weight: number;
  delay: number;
  transmit(signal: number): number;
}
```

#### STDPSynapse 类
实现短期和长期可塑性：
- STDP学习规则
- 权重边界限制
- 延迟传输机制

### 网络拓扑

#### NetworkTopology 类
管理整个神经网络：
- 节点和边的增删改查
- 仿真步进和状态更新
- 网络统计信息收集

## 世界系统

### 设计原则
- **精简高效**: 只保留核心的两个关卡，减少维护负担
- **插件化**: 每个世界配置特定的感受器和效应器组合
- **渐进式难度**: 从简单的光源追踪到复杂的视觉导航

### 世界工厂 (World.ts)
```typescript
static createWorld(width: number, height: number, worldType: string): IWorld {
  switch (worldType) {
    case 'luminous-garden':
      return new LuminousGardenWorld(width, height);
    case 'light-seeker':
      return new LightSeekerWorld(width, height);
    default:
      return new LightSeekerWorld(width, height);
  }
}
```

### 世界插件配置 (WorldPluginConfig.ts)
每个世界定义了特定的插件组合：
- **追光者**: 光感受器 + 梯度移动控制器
- **光影花园**: 光感受器 + 视觉感受器 + 移动控制器 + 旋转控制器

## 开发流程

### 环境配置
```bash
npm install    # 安装依赖
npm run dev    # 开发服务器
npm run build  # 构建生产版本
```

### 开发规范
1. **核心逻辑优先**: 在核心层实现业务逻辑
2. **UI适配**: 创建适配器连接核心层和UI层
3. **事件集成**: 使用EventBus进行组件通信
4. **类型安全**: 实现前先定义接口

### 数据流
1. **用户交互** → UI组件
2. **UI事件** → 事件总线
3. **事件处理** → 核心服务
4. **状态更新** → 全局状态
5. **状态变化** → UI重渲染

## 性能优化

- **PixiJS渲染**: 硬件加速图形，流畅可视化
- **高效更新**: 仅重渲染变化的组件
- **内存管理**: 正确清理事件监听器和图形对象
- **仿真优化**: 优化的神经网络计算循环

## 扩展开发

### 添加新关卡
1. **创建关卡配置**：在 `LevelConfig.ts` 中添加新的关卡配置
2. **实现世界类**：创建对应的世界实现类
3. **配置插件**：在 `WorldPluginConfig.ts` 中定义插件组合
4. **更新工厂**：在 `World.ts` 中添加世界创建逻辑
5. **添加翻译**：在 `LanguageContext.tsx` 中添加多语言支持

### 自定义神经元
1. 实现INeuron接口
2. 在ModuleRegistry中注册
3. 在UI中添加对应的可视化

### 自定义突触
1. 实现ISynapse接口
2. 添加到突触类型枚举
3. 更新适配器逻辑

### 添加新功能
1. 在核心层实现业务逻辑
2. 通过EventBus暴露接口
3. 在UI层添加交互界面
4. 使用适配器连接两层

### 维护指南
- **代码清理**: 定期运行 TypeScript 编译检查，及时修复类型错误
- **文档更新**: 新增功能时同步更新开发文档
- **测试验证**: 确保新功能不影响现有关卡的正常运行
- **性能监控**: 关注大型网络的渲染性能，必要时进行优化

## 常见问题

### 节点无法移动
- 确保没有在创建连接模式
- 按Escape取消当前操作

### 连接创建失败
- 检查起点和终点是否符合规则
- 确保不是重复连接或自环

### 性能问题
- 大型网络可能影响性能
- 考虑使用节点分组或LOD技术

## 调试技巧

1. 使用浏览器开发者工具
2. 检查控制台错误信息
3. 使用React DevTools查看组件状态
4. 在开发环境中启用详细日志
