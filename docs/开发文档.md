## 项目架构

### 设计原则
- **分层架构**: 核心逻辑与UI完全分离
- **事件驱动**: 组件通过EventBus松耦合通信
- **模块化**: 每个模块职责明确，接口清晰
- **类型安全**: 完整的TypeScript类型定义

### 目录结构
```
src/
├── app/              # 应用装配和演示数据
├── core/             # 核心仿真引擎
│   ├── entities/     # 神经元、突触、拓扑等核心实体
│   ├── services/     # 事件总线、状态管理、模块注册
│   ├── simulation/   # 仿真循环管理
│   └── world/        # 世界环境和智能体
├── ui/               # 用户界面层
│   ├── components/   # 可复用UI组件
│   ├── views/        # 页面级组件
│   ├── services/     # UI专用服务
│   ├── adapters/     # 核心与UI间的数据适配器
│   └── styles/       # CSS样式
├── contexts/         # React上下文
└── utils/            # 工具函数
```

## 核心组件

### 事件总线 (EventBus)
集中式事件系统，实现组件间松耦合通信。

### 全局状态 (GlobalState)
基于订阅的响应式状态管理。

### 网络拓扑 (NetworkTopology)
管理神经网络结构、仿真和统计。

### 仿真循环 (SimulationLoop)
控制仿真时序，协调系统更新。

## 神经网络系统

### 神经元模型

#### INeuron 接口
```typescript
interface INeuron {
  update(input: number, deltaTime: number): void;
  reset(): void;
  getState(): NeuronState;
}
```

#### IzhikevichNeuron 类
基于Izhikevich 2003年模型的神经元实现：
- 支持不同类型：input、hidden、output
- 自动根据类型设置合适的参数
- 实现了完整的动力学方程

### 突触模型

#### ISynapse 接口
```typescript
interface ISynapse {
  weight: number;
  delay: number;
  transmit(signal: number): number;
}
```

#### STDPSynapse 类
实现短期和长期可塑性：
- STDP学习规则
- 权重边界限制
- 延迟传输机制

### 网络拓扑

#### NetworkTopology 类
管理整个神经网络：
- 节点和边的增删改查
- 仿真步进和状态更新
- 网络统计信息收集

## 开发流程

### 环境配置
```bash
npm install    # 安装依赖
npm run dev    # 开发服务器
npm run build  # 构建生产版本
```

### 开发规范
1. **核心逻辑优先**: 在核心层实现业务逻辑
2. **UI适配**: 创建适配器连接核心层和UI层
3. **事件集成**: 使用EventBus进行组件通信
4. **类型安全**: 实现前先定义接口

### 数据流
1. **用户交互** → UI组件
2. **UI事件** → 事件总线
3. **事件处理** → 核心服务
4. **状态更新** → 全局状态
5. **状态变化** → UI重渲染

## 常见问题

### 节点无法移动
- 确保没有在创建连接模式
- 按Escape取消当前操作

### 连接创建失败
- 检查起点和终点是否符合规则
- 确保不是重复连接或自环

### 性能问题
- 大型网络可能影响性能
- 考虑使用节点分组或LOD技术
