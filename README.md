# NeuralSoup - 模块化具身智能体仿真平台

一个基于 **TypeScript + React + PixiJS** 的高度可扩展的智能体仿真平台。其核心设计思想是**分层与解耦**，允许研究人员和开发者轻松创建、测试和迭代各种智能体（"大脑"）和它们所处的环境。

## 核心特性

- 🧠 **可插拔大脑**: 支持从简单的 **JavaScript 脚本**到复杂的**脉冲神经网络 (SNN)** 等多种智能模式。
- 🌍 **模块化世界**: 轻松定义和切换不同的世界环境、物理规则和实体。
- 🎨 **高性能渲染**: 基于 PixiJS 的高效渲染引擎，确保仿真过程流畅。
- 🏗️ **分层架构**: `核心逻辑层`与`UI表现层`完全分离，便于独立开发、测试和维护。
- 📢 **事件驱动**: 各模块间通过事件总线进行通信，实现了高度解耦。
- 🎛️ **可视化编辑**: 内置SNN拓扑编辑器，支持实时交互式神经网络设计。
- 📊 **实时监控**: 丰富的仿真统计信息和可视化反馈。

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器 (通常在 http://localhost:5173)
npm run dev
```

## 项目结构

```
src/
├── app/          # ✨ 应用总装配
├── core/         # ✨ 纯粹的核心仿真引擎 (TS)
├── modules/      # ✨ 可插拔模块 (大脑, 传感器, 世界)
├── ui/           # ✨ React & PIXI.js 用户界面
└── shared/       # ✨ 共享接口定义 (Contracts)
```

## 使用指南

### 仿真控制
- 使用顶部导航栏的播放按钮来启动/停止仿真
- 在右侧控制面板中实时调整各项参数

### SNN编辑器
- 切换到"SNN 编辑器"标签页
- **双击**画布创建新的神经元节点
- **左键拖拽**移动节点位置或框选多个节点
- **Ctrl+左键**多选节点和组
- **Ctrl+右键**创建神经元连接
- **右键拖拽**平移画布视图
- **鼠标滚轮**缩放画布（以中心为原点）
- **Del键**删除选中的元素

### 脚本编辑
- 在"脚本编辑"标签页中编写JavaScript代码
- 定义智能体的行为逻辑
- 实时应用脚本更改到仿真中
