# NeuralSoup 🧠

模块化神经网络仿真平台，支持脉冲神经网络(SNN)的可视化编辑和实时仿真。

## 特性

- 🎛️ **可视化编辑**: 拖拽式神经网络拓扑编辑器
- 🧠 **实时仿真**: 支持Izhikevich神经元模型和STDP学习
- 🎨 **高性能渲染**: 基于PixiJS的流畅可视化
- 🏗️ **模块化架构**: 核心逻辑与UI完全分离

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器 (通常在 http://localhost:5173)
npm run dev
```

## 基本操作

### 神经网络编辑
- **双击**画布创建神经元
- **Ctrl+右键**创建连接
- **左键拖拽**移动节点
- **右键拖拽**平移画布
- **滚轮**缩放画布
- **Delete**删除选中元素

### 仿真控制
- 点击播放按钮开始/停止仿真
- 右侧面板调整参数

## 技术栈

- **核心**: TypeScript
- **UI**: React + PixiJS
- **构建**: Vite
- **架构**: 事件驱动分层架构
